# powergame · 首创游戏

## 《冰火旅人》— 单文件剧情 RPG

维斯特洛大陆，长夜将至。以琼恩·雪诺之名探索五张地图、经历七章主线、招募伙伴、驯服魔物，
最终在临冬城下与夜王决战。Three.js 真 3D 探索 + 回合制战斗，单文件即开即玩，无需联网、无需安装。

## 快速开始

用 Chrome（或其他现代浏览器）打开 `powergame.html` 即可。

## 目录说明

| 路径 | 内容 |
|------|------|
| `powergame.html` | 游戏本体（单文件，~4500 行） |
| `assets/` | 2D 素材（Kenney UI / LPC / medieval-fantasy） |
| `assets3d/` | 3D 资产：three.min.js、adapter3d.js、GLB base64（chars/mobs/props） |
| `MANUAL.md` | 游戏说明文档（按键/界面/战斗/养成/图鉴） |
| `WALKTHROUGH.md` | 全流程攻略（七章主线 + 16 支线 + 驯服指南） |
| `screenshots/` | 游戏截图留档 |
| `powergame_v3_backup.html` | v3 开放世界版备份 |
| `_shot.js` / `_smoke.js` / `_shotg.js` | headless 截图与回归脚本（开发用） |
| `_dl3d.js` / `_bake3d.js` / `probe3d.html` | 3D 模型下载/烘焙/验证工具（开发用） |
